# 🌸 Flower Classification Model using Deep Learning

## 📌 Overview
This project is a Deep Learning-based Flower Classification System that identifies different flower species from images using Convolutional Neural Networks (CNN). The model is trained on flower image datasets and can accurately classify flower categories through image recognition techniques.

This project demonstrates the complete workflow of an Image Classification system including preprocessing, model training, evaluation, and prediction visualization.

## 📊 Workflow

### 1️⃣ Data Collection
Flower image dataset is collected and organized into different categories.

### 2️⃣ Data Preprocessing
- Image resizing
- Normalization
- Label encoding
- Data augmentation

### 3️⃣ Model Building
A Convolutional Neural Network (CNN) is created using TensorFlow/Keras.

### 4️⃣ Model Training
The model is trained on flower images to learn patterns and features.

### 5️⃣ Model Evaluation
Performance is evaluated using:
- Accuracy
- Loss graphs
- Validation metrics

### 6️⃣ Prediction
The trained model predicts flower species from unseen images.
